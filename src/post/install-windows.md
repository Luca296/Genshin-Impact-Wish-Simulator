# Install on Windows

Extract the complete Genshin Wish Offline package and open `Genshin Wish Offline.exe`. Keep the executable with the included `resources`, `locales` and DLL files. The application is unsigned.

The app stores progress separately in `%APPDATA%\GenshinWishOffline`, so replacing the application folder does not remove your save. To remove the app, delete its extracted folder. Delete the profile separately only if you also want to remove your saves and backups. See [DESKTOP.md](../../DESKTOP.md) for backup and restore instructions.
