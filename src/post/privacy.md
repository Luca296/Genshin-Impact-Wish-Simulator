# Local data and privacy

Genshin Wish Offline stores settings and game progress in the desktop profile on this computer. On Windows, the default profile is `%APPDATA%\GenshinWishOffline`. It contains local storage, IndexedDB, cookies and automatic backups.

The packaged app blocks external network requests. Exported backups are files you choose to save, and can contain your inventory, history, settings and custom banners. Anyone with a backup file can read its contents. Keep copies somewhere safe if you want to recover progress after a drive failure or reset.

For backup and restore instructions, see [DESKTOP.md](../../DESKTOP.md).
